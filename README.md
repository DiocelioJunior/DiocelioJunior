## 🚀 Projetos

### 🖨️ Line UP DTF

<p align="left">
<strong>Projeto publicado</strong>
</p>

<p align="left">
O <strong>Line UP DTF</strong> é uma aplicação desenvolvida para auxiliar na <strong>criação, tratamento e padronização de templates para impressão DTF</strong>, buscando reduzir processos manuais e tornar o fluxo de trabalho mais organizado.
</p>

<p align="left">
Entre os principais objetivos estão:

<li>Redução de trabalho manual</li>
</ul>

<strong>Projeto atual — uso pessoal</strong>
